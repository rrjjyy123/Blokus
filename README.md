# 블로커스 웹앱

PC·태블릿 한 대를 여럿이 둘러앉아 플레이하는 블로커스(Blokus) 패스앤플레이 웹앱입니다.
서버·계정 없이 브라우저 안에서만 돌아갑니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5180
npm run test     # 규칙·점수 로직 테스트 42개
npm run build    # dist/ 생성
```

## 배포 (Vercel)

프로젝트 폴더에서 아래를 실행하고 안내에 따라 로그인·프로젝트 이름을 정하면 됩니다.
빌드 설정은 Vercel이 Vite 프로젝트로 자동 인식합니다.

```bash
npx vercel --prod
```

GitHub에 올려 두고 Vercel 대시보드에서 저장소를 연결하면, 이후로는 푸시할 때마다 자동 배포됩니다.
Netlify·GitHub Pages도 동일하게 `npm run build` 결과인 `dist/` 폴더를 올리면 됩니다.
(GitHub Pages처럼 하위 경로에 올릴 때만 `vite.config.ts`의 `base`를 `'/저장소이름/'`으로 바꿔 주세요.)

## 게임 규칙 요약

- 20×20 보드, 색당 조각 21종(총 89칸)
- 첫 조각은 자기 색 코너 칸을 덮어야 함
- 이후 조각은 같은 색과 **꼭짓점으로만** 닿아야 하고, **변이 닿으면 반칙**. 다른 색과는 제약 없음
- 놓을 자리가 없는 색은 자동으로 차례를 넘기고 탈락, 전원 불가 시 종료
- 점수: 남은 칸 수만큼 −1점, 21개 전부 놓으면 +15, 그 마지막이 1칸짜리면 +5

인원별 진행

| 인원 | 방식 |
|---|---|
| 4인 | 각자 한 색 |
| 3인 | 파랑·노랑·빨강 세 색만 사용, 초록 미사용 |
| 2인 | 한 사람이 대각 두 색(파랑+빨강 / 노랑+초록), 점수 합산 |

## 조작

자리를 정하는 방법은 두 가지지만, **확정은 언제나 「여기에 놓기」 한 번**을 거칩니다.
손이 미끄러져 엉뚱한 곳에 놓이는 사고를 막기 위해서입니다.

**끌어다 놓기** — 트레이의 조각을 눌러 보드까지 끌고 가서 손을 떼면 그 자리에 미리보기가 놓입니다.
보드에 떠 있는 미리보기를 다시 잡아 끌면 자리를 옮길 수 있습니다.

**탭해서 놓기** — 조각을 탭해 고르고 보드의 칸을 탭하면 그 자리에 미리보기가 놓입니다.

둘 다 미리보기까지만 하고, 놓을 수 있는 자리면 「여기에 놓기」 버튼이 켜지며 깜박입니다.
그 전까지는 몇 번이든 다시 끌거나 회전해 고칠 수 있습니다.

| 동작 | 방법 |
|---|---|
| 조각 선택 | 트레이에서 탭 |
| 자리 지정 | 보드로 끌어다 놓기, 또는 보드의 칸을 탭 |
| 방향 조정 | ↺ ↻ 회전, ⇋ 뒤집기 |
| 확정 | 「여기에 놓기」 (놓을 수 있을 때만 활성) |

키보드 보조: `E`/`R` 회전, `F` 뒤집기, 방향키 미세 이동, `Enter` 놓기, `Esc` 선택 해제.

미리보기는 놓을 수 있으면 자기 색 반투명, 놓을 수 없으면 빨간색으로 표시되고
상단 배너에 이유가 뜹니다.

## 구조

```
src/
├─ game/          규칙 엔진 (UI와 완전히 분리)
│  ├─ pieces.ts     21종 조각 + 회전·반전 91방향 생성
│  ├─ rules.ts      배치 판정, 합법수 탐색
│  ├─ scoring.ts    점수·보너스·순위
│  ├─ variants.ts   인원별 색 구성, 코너, 좌석 회전각
│  └─ __tests__/    Vitest
├─ state/         gameReducer(턴·자동패스·종료), localStorage 저장
├─ components/    화면
└─ styles/        색 토큰 + 전역 스타일
```

조각 방향은 손으로 적지 않고 회전·반전을 런타임에 생성한 뒤 중복을 제거합니다
(총 91방향). 테스트가 조각별 방향 수와 총 89칸을 검증합니다.

## 중간에 끝내기

수업 시간이 모자라 판을 끝까지 못 갈 때를 위해 오른쪽 아래 「여기까지 하고 점수 내기」로
그 자리에서 정산할 수 있습니다. 확인 창을 한 번 거치고, 지금 보드에 놓인 조각만으로 점수를 냅니다
— 남은 조각은 그대로 감점이고 21개를 다 놓지 못한 사람은 완주 보너스를 받지 못합니다.
결과 화면에 중간 정산이었다는 표시가 함께 남습니다.

## 저장

진행 중인 판은 `localStorage`에 자동 저장되어, 새로고침하거나 앱이 뒤로 밀려도
시작 화면의 「하던 게임 이어서 하기」로 복구됩니다.
